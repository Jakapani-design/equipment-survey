กลับหน้าแบบสำรวจ

นโยบายความเป็นส่วนตัว

Equipment Survey เป็นเว็บสำรวจจำนวนอุปกรณ์แยกตามสาขา ใช้งานผ่าน GitHub Pages และจัดเก็บข้อมูลสำรวจใน Google Sheets ของผู้ดูแล ปรับปรุงวันที่ 23 ตุลาคม 2026

ข้อมูลที่เว็บใช้งาน

เว็บอ่านรายชื่อสาขา อุปกรณ์ จำนวนที่ต้องใช้ เหตุผล ชื่อผู้สำรวจ วันที่สำรวจ และหมายเหตุจากชีตเป้าหมาย และบันทึกข้อมูลที่ผู้ใช้ส่งจากแบบสำรวจกลับไปยังชีตนั้น

สิทธิ์ Google

เว็บใช้ Google OAuth และ Google Sheets API เพื่ออ่านและแก้ไขชีต ต้องให้ผู้ใช้เข้าสู่ระบบและอนุญาตก่อน สิทธิ์ spreadsheets ที่ Google แสดงครอบคลุมชีตในบัญชีผู้ใช้ แต่โค้ดเว็บนี้กำหนด Spreadsheet ID เป้าหมายไว้เพียงไฟล์เดียว เว็บไม่ขอรหัสผ่าน Google และไม่เก็บรหัสผ่าน

วิธีจัดเก็บและส่งข้อมูล

หน้าเว็บเรียก Google Sheets API โดยตรงจากเบราว์เซอร์ โทเค็นสิทธิ์เข้าถึงและฉบับร่างที่ยังไม่บันทึกอยู่ในหน่วยความจำของหน้าเว็บ ไม่บันทึกลง localStorage หรือ repository เมื่อปิดหรือโหลดหน้าใหม่ ข้อมูลชั่วคราวเหล่านี้จะหาย ข้อมูลที่กดบันทึกแล้วจะอยู่ใน Google Sheets จนกว่าผู้มีสิทธิ์หรือผู้ดูแลจะเปลี่ยนหรือลบ

บุคคลที่เข้าถึงข้อมูล

Google ประมวลผลการเข้าสู่ระบบและคำขออ่าน/บันทึกชีต ส่วน GitHub ให้บริการไฟล์เว็บไซต์ การเข้าถึงข้อมูลสำรวจเป็นไปตามสิทธิ์การแชร์ของชีต ปัจจุบันชีตตั้งให้ทุกคนที่มีลิงก์แก้ไขได้ ผู้ที่มีลิงก์จึงอาจอ่าน เปลี่ยนแปลง หรือลบข้อมูลสำรวจได้ โปรดไม่กรอกข้อมูลอ่อนไหวหรือข้อมูลที่ไม่เกี่ยวกับการสำรวจ

การควบคุมและลบข้อมูล

ผู้ใช้สามารถเพิกถอนสิทธิ์ของแอปผ่านหน้าการเชื่อมต่อบัญชี Google การเพิกถอนสิทธิ์ไม่ลบข้อมูลที่บันทึกในชีตแล้ว หากต้องการแก้ไขหรือลบข้อมูลสำรวจ ให้ติดต่อผู้ดูแลด้านล่าง หรือแก้ไขในชีตตามสิทธิ์ที่ได้รับ
